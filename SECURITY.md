# Security policy

Please avoid filing a public issue that contains a pairing token, database,
learner source, credentials, private paths, or exploit details.

Use GitHub's private vulnerability reporting feature for this repository when
available. Include the affected version, reproduction steps using disposable
data, impact, and a suggested mitigation. Do not test against another person's
machine/account or publish secrets while demonstrating the issue.

Ordinary bugs without sensitive details can use the bug-report template.
