DSA Accountability 1.1.0 — Windows quick start

1. Keep this entire extracted folder together.
2. Run DSAAccountability.exe.
3. Choose your Day 1, learner-repository folder, GitHub preference, and Windows startup preference.
4. In Chrome, open chrome://extensions, enable Developer mode, choose Load unpacked, and select this folder's chrome-extension directory.
5. Copy the pairing token from First Run/Settings into the extension popup and choose Save & Test Connection.
6. Start the active curriculum day.

Your progress and pairing token stay under %LOCALAPPDATA%\DSAAccountability and are not included in this release.
