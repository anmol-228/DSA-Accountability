# DSA Accountability v1.1.0

## Highlights

- Choose any Day 1; a fresh 135-day schedule is generated without changing the
  reference curriculum.
- Choose any learner-repository folder/name and use local Git without GitHub.
- Fresh Java LeetCode Accepted detection, reflections, revision scheduling,
  narrow Git commits, optional push, and retry remain built in.
- New manual installation/user/developer documentation and a generic safe LLM
  setup prompt.

## Requirements

Windows 10/11 x64, JDK 17+, Git, Chrome, and optionally VS Code. The prebuilt
ZIP does not require Python. Source builds require Python 3.12+ and Node.js for
extension tests.

## Install

Download and fully extract `DSAAccountability-Windows-x64-v1.1.0.zip`, run the
executable, complete First Run, then load/pair the included unpacked extension.

## Known limitations

- Windows is the supported desktop target.
- Java is the only supported solution language.
- The extension is distributed unpacked, not through Chrome Web Store.
- LeetCode DOM changes can require a tested extension update.
- GitHub is optional, but task code archival requires local Git.

## Upgrade

Close the old app and create a Backup now snapshot before replacing files. The
existing Day 1 is inferred from the stored curriculum and preserved. If the
install folder changes, refresh the startup shortcut and reload the extension.
